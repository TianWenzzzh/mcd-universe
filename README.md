# 麦门宇宙 McUniverse

> 你的每一单，都是麦门宇宙里的一颗星。

基于麦当劳中国官方 MCP 开发的 Skill：拉取你的历史订单，生成个人「麦门星图」与「麦门人格」鉴定，一键导出分享卡。数据全程本地处理，Token 不出本机。

**麦当劳程序员创意开发大赛（WorkBuddy × 麦当劳 · 1024 程序员节）参赛作品**

## 功能规划

- **麦门星图**：每一笔订单化为一颗星——颜色=餐品品类，星等=消费频次，连成属于你的星座
- **麦门人格**：基于订单模式的趣味鉴定（深夜麦门人 / 优惠券猎人 / 甜点星住民……），全部正面向
- **分享卡**：粒子视觉报告页一键导出，晒出你的麦门宇宙
- **积分哨兵**：积分到期提醒，守住每一分

## 快速开始

```bash
# 1. 申请麦当劳 MCP Token：https://open.mcd.cn/mcp （手机号登录 → 控制台 → 激活）
# 2. 配置环境变量
export MCD_MCP_TOKEN="your_token_here"

# 3. 运行（详见文档）
```

## 技术栈

Python（订单解析与星图引擎）+ 纯 HTML/Canvas（星图渲染，零依赖零外链，离线可用）。
